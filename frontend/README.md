# Canada Interns Frontend

## Stack
- Next.js 14 (App Router)
- Tailwind CSS
- Supabase Auth or Clerk

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and fill in Supabase/Clerk keys
3. Run the dev server:
   ```bash
   npm run dev
   ```

## Features
- Internship board with filters
- Real-time updates
- Track/save internships
- Responsive, editorial UI
